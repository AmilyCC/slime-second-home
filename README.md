# 史萊姆好玩遊戲區 - 史萊姆的第二個家

以史萊姆原站文字版遊戲區為參考的靜態連結表格，收錄 50 個遊戲入口，每頁 15 個，共 4 頁。

## 執行與部署

`dist/` 為完整靜態網站，無套件依賴與建置步驟。GitHub Pages 使用 `.github/workflows/pages.yml` 自動部署 `dist/`；更新主分支的網站檔案後即會部署。

網站：https://amilycc.github.io/slime-second-home/

## 資料

`dist/games.json` 保存遊戲名稱、簡介、網址、來源留言及讚數。保留 2026/10/22 收錄的 20 個遊戲，另於 2026/10/23 從原貼文當次可讀取的留言補入 30 個不同遊戲，再依記錄讚數排序。原有遊戲沿用首次收錄的讚數；新增遊戲使用本次讀取時的讚數，不是全串即時、精確的前 50 名。

重複推薦不累加；同則留言中的不同遊戲共用該則讚數，引用其他貼文時使用推薦留言本身的讚數。同讚數依收錄順序排列。遊戲名稱以繁體中文顯示，原名保存在 `original` 欄位。部分入口為遊戲合集或互動玩具；登入及收費規則依各原站為準。
