# 史萊姆好玩遊戲區 - 史萊姆的第二個家

以史萊姆原站文字版遊戲區為參考的靜態連結表格，收錄 20 個遊戲入口。

## 執行與部署

`dist/` 為完整靜態網站，無套件依賴與建置步驟。以靜態網站服務部署 `dist/` 即可。

## 資料

`dist/games.json` 保存遊戲名稱、簡介、網址、來源留言及讚數。依 2026/10/22 本次可讀取、附有遊戲連結的推薦留言讚數排序，不是全串精確排名。重複推薦採最高讚數，不累加；同則留言中的不同遊戲共用該則讚數。第 20 款與 Neverdex 同為 32 讚，依讀取順序選入。
